🎾 My Tennis Club

Professional Member Management System

About

My Tennis Club is a web-based application designed to streamline tennis club member management. Built with Django, it provides administrators with an intuitive interface to efficiently manage member records, making it easy to add, edit, view, and delete member information.

Key Features

👥 Member Management

Add, edit, view, and delete member records with ease. Keep all member information organized and accessible.

📊 User-Friendly Interface

Intuitive dashboard designed for administrators to manage the tennis club efficiently.

🔒 Secure & Reliable

Built on Django framework with robust database management for data integrity and security.

⚡ Fast & Responsive

Quick loading times and responsive design for desktop and mobile devices.

Technology Stack

Django
Python
SQLite
HTML/CSS
